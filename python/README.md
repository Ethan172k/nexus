# NEXUS | Computational Thinking Using Python

Esta é a versão em Python do projeto acadêmico NEXUS, preparada por Octavio de Souza Ribeiro. Ela roda no terminal, sem dependências externas e sem conexão com o WebChat, o Node-RED ou o bot do Telegram.

## Executar

Na raiz do repositório, com Python 3.10 ou mais recente:

```bash
cd python
python3 nexus_gs.py
```

Use apenas dados fictícios. O menu permite registrar e consultar SOS, simular conexões e encaminhamento na rede, tentar encaminhar pedidos pendentes e exportar um relatório CSV. O encaminhamento é uma simulação e não aciona equipes de resgate.

Os arquivos `nexus_dados.json` e `relatorio_nexus.csv` são gerados no diretório atual e não devem ser versionados. Os materiais da disciplina para o Portal do Aluno ficam separados deste código.
